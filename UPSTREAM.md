# Provenance

Flock is derived from the MIT-licensed croc project by Zack Scholl and
contributors. The fork point is commit
`b6d9a35fe63e05c67ca2f4a3e6e2320c07f6edff`.

The original copyright and license remain in LICENSE. Flock adds native QUIC
file-data transport and an agent-first JSON interface. The installed command,
Go module namespace, release archives, and package metadata belong to Flock.
The original CLI and its tests remain under `cmd/croc-legacy` for reference.
